# MindMate - Student Mental Wellness Tracker

**MindMate** is a responsive, dark-themed, glassmorphic single-page web application designed to support competitive exam aspirants (preparing for UPSC, JEE, NEET, GATE, CAT, CUET, and Board Exams) in monitoring and optimizing their mental wellness. 

Built using a lightweight and efficient vanilla architecture, MindMate integrates the **Gemini 2.5 API** as an AI Wellness Coach to provide personalized encouragement, time management recommendations, and evidence-based stress-reduction suggestions.

---

## 🚀 Core Features

1. **Daily Mood Check-In**: Record daily mood, energy levels, confidence, study hours, sleep duration, and water intake.
2. **Stress Trigger Tracker**: Track academic and environmental stressors (Mock Test Performance, Family Pressure, Burnout, comparison, etc.) along with custom user-defined triggers. Dynamic trigger frequency graphs analyze recurring stressors over time.
3. **Reflection Journal**: Prompt students with self-care journaling questions (What went well today? What challenged you? What are you proud of? What to improve tomorrow?) to encourage mindfulness.
4. **Gemini AI Wellness Coach**: Leveraging `gemini-2.5-flash` to analyze daily wellness metrics and provide custom tips, motivator messages, and study recommendations.
5. **Wellness Dashboard**: Native circular gauge displaying a weighted Wellness Score (0-100), categorization zones (Healthy, Moderate Risk, Burnout Risk), average study/sleep trends, and canvas-based historical trend graphs.
6. **Exam Support Mode**: Exam-specific advice generated by the AI coach matching the target test selected.
7. **Emergency Support Banner**: A dynamic alert activated when chronic burnout signs or repeated "Overwhelmed" moods are detected across check-ins, advising students to seek support from family, teachers, or counselors.

---

## 🛠️ Tech Stack & Architecture

- **Frontend Structure**: Semantic HTML5 & Responsive CSS3 (Flexbox & Grid).
- **Core Engine**: Vanilla JavaScript (Modular ES modules refactored for zero-dependency local `file://` loader compatibility).
- **AI Integrations**: Gemini 2.5 API (using `gemini-2.5-flash`).
- **Data Stores**: LocalStorage persistence for complete offline security.
- **Visuals**: Clean canvas renderers for line graphs and bar charts to ensure zero bundle bloat.

## ⚙️ Configuration and Launch

1. Clone or download this repository.
2. Double-click the [index.html](file:///f:/main_challange/index.html) file to launch in any modern browser.
3. Tap the **Settings** icon (gear symbol in the top right) to input your Gemini Developer API Key. The key is stored safely in LocalStorage.
